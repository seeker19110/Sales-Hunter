# Nhật ký phiên

Mỗi ngày có thể có một file `YYYY-MM-DD.md`. Chỉ ghi thông tin phiên sau cần để tiếp tục, không chép lại toàn bộ hội thoại.

```markdown
# Phiên YYYY-MM-DD

## Đã hoàn thành
- <PR/commit và bằng chứng>

## Đang dở
- <việc, lý do dở, trạng thái có thể tiếp tục>

## PR đang mở
- <URL, head SHA, check còn chờ>

## Bẫy mới
- <đã ghi vào TRAPS.md hay chưa>

## Không được quên
- <ràng buộc/quyết định có ảnh hưởng phiên sau>
```

Không ghi token, cookie, payload khách hàng hoặc dữ liệu thương mại thật vào nhật ký.
